# YOUR GYM photos

Every photo on the site is loaded from this folder. They are **stock
placeholders** — swap in real photos of your gym by saving a new image over the
file with the same name. Nothing else needs to change.

Landscape images around 1600px wide at ~80% JPEG quality work best
(`hero.jpg` wants ~1920px).

| File | Where it appears |
|---|---|
| `hero.jpg` | Top of the home page, behind the headline |
| `background.jpg` | Behind every page, under a dark overlay |
| `facility-free-weights.jpg` | Facilities: free weights |
| `facility-strength.jpg` | Facilities: racks and platforms |
| `facility-machines.jpg` | Facilities: machines and cycling |
| `facility-cardio.jpg` | Facilities: cardio deck |
| `facility-studio.jpg` | Facilities: group studio |
| `facility-functional.jpg` | Facilities: functional / HIIT zone |
| `class-strength.jpg`, `class-core.jpg` | Class timetable highlights |
| `personal-training.jpg` | Personal training section |
| `app-member.jpg` | "Member app" section |
| `join.jpg` | Final "join" banner and free-pass page |
| `auth.jpg` | Log-in and sign-up pages |
